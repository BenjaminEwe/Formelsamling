\section{Trees}

\subsection{2-3 Trees}
A 2-3 tree is a self-balancing search tree where every node has either 2 or 3 children, and all leaves are at the same depth. It maintains sorted order and allows for efficient insertion, deletion, and search operations.

\emph{2-nodes} have 1 key and 2 children. \emph{3-nodes} have 2 keys and 3 children.

In a 2-3 tree, the amount and placement of 2 and 3 nodes is unimportant.

\subsubsection{Inserting}
To insert a new key, we search for it from the root down to the leaf level.

If it is a 2-node, we add the key and turn it into a 3-node. \\
If it is a 3-node, we make a temporary 4-node with the new key. The middel value is sent inserted to the parent key, and the left and right values become 2-nodes. If the parent is a 3-node, we repeat this process up the tree until we reach a 2-node or the root. \\
If we reach the root and it is a 3-node, we make a temporary 4-node with the new key. The middel value becomes the new root, and the left and right values become 2-nodes.

Both search and insert have \timeComplexity{\lg n}
